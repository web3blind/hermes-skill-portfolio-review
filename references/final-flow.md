# Final Flow

## Purpose

After the review, close the loop in a consistent way. The user should leave with a clear interpretation, concrete next actions, a saved-history step, and a reminder suggestion.

## Default closing structure

Use this order:

1. `Visible facts`
2. `Likely issues`
3. `Candidate actions`
4. `What is missing`
5. `Next step`

## Default final block

If the review was useful, end with a block like this:

```text
Next step:
- save this as the current monthly snapshot
- compare against it at the next review
- add a monthly /portfoleo reminder if you do not already have one
```

## Stronger variant

If the user explicitly said they tend to forget, use:

```text
Next step:
- save this as the current monthly snapshot
- add a monthly /portfoleo reminder now so this review does not depend on memory
```

## Weekly variant

If the review is intentionally light and the portfolio is active, use:

```text
Next step:
- save the key changes from this check
- keep the full comparison for the monthly review
- add a weekly light /portfoleo reminder only if the portfolio changes often enough to justify it
```

## Style rules

- Keep the close direct and operational.
- End with one clear recommendation, not a long menu.
- Prefer monthly cadence by default.
- Do not ask the user to do five things at once.
