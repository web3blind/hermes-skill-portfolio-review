# Crypto Review

## Objective

Review the portfolio for survival, concentration control, stable buffer quality, and thesis discipline, not for guessing tops.

## Default structure

Use this as the current starting structure unless the user changes it:

- `BTC 15%`
- `ETH 15%`
- `Stables 30%`
- `Thesis positions 24%`
- `Venture positions 16%`

For practical screenshot reviews, the exact named positions matter less than:

- core vs non-core
- stable buffer
- concentration
- presence or absence of a thesis

## Core rules

- stay in the game
- fixation of profit is part of the strategy
- hope is not a holding reason
- if a position has no thesis, it is not an investment
- for large positions, test whether you would buy the asset today if you did not already hold it
- screenshot review is enough for periodic judgment if the snapshots are saved consistently

## Review cadence

Use this skill mainly for:

- weekly light review
- monthly full review
- post-airdrop review

## Current-position buy test

For sufficiently large current positions, always ask:

`If I did not already hold this asset, would I buy it now at the current price and with the current thesis?`

Use this to fight sunk-cost bias and portfolio inertia.

If the answer is no:
- do not automatically sell immediately;
- mark the asset as `thesis check required`, `trim candidate`, or `exit candidate`;
- require a clear reason to keep holding.

Apply mainly to meaningful positions, not dust or tiny experimental holdings.

## Candidate actions

Typical outputs:

- `hold`
- `trim candidate`
- `thesis check required`
- `stable buffer too low`
- `venture basket too large`
- `exit candidate`

## Airdrops

Use the same first question every time:

`If I had not received this token for free, would I buy it now with cash?`

If no, default to selling.

If yes, force a thesis and max size before treating it as a hold.

## DCA Strategy (Dollar Cost Averaging)

### Why DCA
- Crypto is volatile — trying to time the bottom rarely works
- Prices can swing 30-50% in weeks
- DCA removes emotion from buying decisions

### DCA Rules
1. **Never invest lump sum** — split purchases over 6-12 months
2. **Buy on schedule, not on price** — fixed amount monthly, regardless of price
3. **Buy more on dips** — if price drops 20%+ from your average, optionally increase purchase
4. **Set price ranges** — e.g., buy BTC if price is $50K-$80K

### Example with volatility
- BTC can drop from $80K to $45K, then rise to $90K
- Instead of waiting for "right moment" — buy $150-200 monthly
- If BTC drops to $45K — consider buying slightly more ($250)
- If BTC jumps to $90K — still buy $150 (you'll average in at higher price, but you're in the game)

### Target calculation
1. Calculate target allocation (e.g., 15% BTC, 15% ETH)
2. Subtract current holdings
3. Divide by 12 months = monthly purchase amount
4. Adjust if portfolio grows

### Key principle
**"Time in the market beats timing the market"**
