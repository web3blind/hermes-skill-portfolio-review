# Portfolio Review

Public Hermes skill export prepared from a private Hermes skill.

## Install / use

Copy this folder into your Hermes skills directory or submit it to a skills catalog after running the checks below.

## Local files

Do not commit local runtime files such as `.env`, `state.json`, `config.json`, `addresses.conf`, logs, or debug outputs. Use the provided `*.example.*` files as templates.

## Verification before publishing

- Run a static skill security scan.
- Run a secret/private-marker scan.
- Run syntax checks for scripts, if any.
- Confirm `git status --ignored` does not show private files as trackable.
